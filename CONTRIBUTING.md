# Contributing to eBikeR

Thank you for your interest in contributing to **eBikeR**! We welcome bug reports, feature requests, documentation improvements, and code contributions.

## Code of Conduct
By participating, you are expected to uphold our open-source community standards. Please be respectful and constructive in all interactions.

## How to Contribute

### 1. Fork & Clone
Fork the repository to your GitHub account and clone your fork locally:
```bash
git clone https://github.com/your-username/eBikeR.git
cd eBikeR
```

### 2. Create a Feature Branch
Create a descriptive branch for your changes:
```bash
git checkout -b feature/amazing-feature
```

### 3. Commit Standards
Write clear, concise commit messages following conventional commit standards:
- `feat(auth): add multi-factor authentication support`
- `fix(bookings): resolve duration calculation edge case`
- `docs(readme): update deployment instructions`

### 4. Run Tests
Ensure all unit and integration tests pass before submitting your PR:
```bash
cd ebikeRent/backend
pytest
```

### 5. Submit Pull Request
Push your branch to GitHub and open a Pull Request against the `main` branch.
